# СТЕНА

Нарративная головоломка от первого лица. Электрик и программист открывает дверь «Электрощитовая» на шестом этаже
и попадает в Стену — мегаструктуру высотой в пару сотен километров, опоясывающую Землю по экватору.

**Играть:** https://tsenze13.github.io/STENA/ · бета: https://tsenze13.github.io/STENA/beta/ (нужны клавиатура и мышь, лучше в наушниках).

## Управление
- **W A S D** — идти, **Shift** — быстрее, **мышь** — смотреть
- **E** — взаимодействовать, **F** — фонарик, **Tab** — наручный терминал ПТ-1 (1/2/3 — вкладки), **Esc** — пауза
- В терминале пиши команды латиницей (раскладку переключать не нужно) и жми Enter. Начни с `HELP`.
