# СТЕНА

Нарративная головоломка от первого лица на Godot 4.7. Электрик и программист открывает дверь «Электрощитовая»
на шестом этаже и попадает в Стену — мегаструктуру высотой в пару сотен километров, опоясывающую Землю по экватору.

## Как играть
Скачай архив сборки для Windows, распакуй и запусти `STENA.exe`. Устанавливать ничего не нужно.

## Как открыть проект
Нужен Godot 4.7.2 (https://godotengine.org/download). В Godot: «Импорт» → выбрать `project.godot` в этой папке → F5.

## Управление
- **W A S D** — идти, **Shift** — быстрее, **мышь** — смотреть
- **E** — взаимодействовать, **F** — фонарик, **Tab** — наручный терминал ПТ-1 (1/2/3 — вкладки), **Esc** — пауза
- В терминале пиши команды латиницей (раскладку переключать не нужно) и жми Enter. Начни с `HELP`.

## Что сейчас есть (0.4-бета)
Глава 0: подъезд, дверь, высокий коридор с мостками и проводами, щиток ЩР-6, терминал ЩИТ-80, ПТ-1 на руке,
решётка ГД-6 и свет до горизонта.

Концепция игры — в [docs/concept.md](docs/concept.md). Старая браузерная версия — в `web_prototype/` (не развивается).
