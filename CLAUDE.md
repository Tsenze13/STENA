# СТЕНА — правила работы и карта кода

## Как мы работаем
- Отвечать по-русски, просто, без жаргона. Автор часто пишет голосом — сообщения бывают сумбурными, это нормально.
- Автор не программист: код пишет Claude, автор решает, что делать, и тестирует.
- **Игра делается на Godot, не в браузере.** Автор получает готовую сборку для Windows (`.exe` в архиве).
  Решения о движке, формате и платформе — только с явного «да» автора.
- Порядок: сначала **бета** (ветка `beta`/`godot`, сборка с пометкой «бета»), автор проверяет, потом слияние в `main`.
- Коммитим только после того, как проходит автотест.
- Версии: `0.4`, `0.5`… бета — `0.4-бета`. Номер в `scripts/main.gd` (`VERSION`) и `project.godot` (`config/version`).
- Концепция и сюжет: `docs/concept.md`. Новое решение автора по сюжету или механикам — записывать туда.
- Старая браузерная версия лежит в `web_prototype/` только для истории, её не развиваем.

## Как устроено
Godot 4.7.2, GDScript. Сцена `scenes/main.tscn` пустая: всё строится кодом при запуске (`scripts/main.gd`).
Все текстуры и звуки процедурные (шум FastNoiseLite, Image, синтез звука), файлов-ассетов нет.
Рендер — Forward+ (объёмный туман, SSR, SSAO, тени); в песочнице тесты идут на Compatibility (OpenGL, llvmpipe),
там нет объёмного тумана и SSR — на скриншотах тестов картинка проще, чем у автора.

## Правила кода
- Новый интерактивный объект: `Geo.act_zone(...)` с именем `act` + подсказка в `_prompt_for` и действие в `interact` (main.gd).
- Новая стена — `wall(...)` или `Geo.solid(...)` в world.gd, иначе сквозь неё можно пройти.
- Свет — только через лампы и группы (`L.set_group`), не ставить OmniLight на каждую лампу.
- Мелкие детали — через `B.box/B.cyl/B.add` (Batch), а не отдельными узлами.
- Изменения питания — только через `G.set_line(ключ, значение)`.
- В GDScript `:=` не выводит тип из `min/max/abs` — писать `minf/maxf/absf` или явный тип.

## Godot в песочнице
Godot и шаблоны экспорта качаются с GitHub (godotengine/godot, релиз 4.7.2-stable):
- `Godot_v4.7.2-stable_linux.x86_64.zip` — редактор/запуск;
- `Godot_v4.7.2-stable_export_templates.tpz` → `~/.local/share/godot/export_templates/4.7.2.stable/`
  (нужны `windows_release_x86_64.exe` и `version.txt`).

Команды (`GD` — путь к бинарнику):
- импорт и проверка скриптов: `$GD --headless --path . --import`
- автотест: `xvfb-run -a -s "-screen 0 1280x720x24" $GD --path . --rendering-method gl_compatibility --resolution 800x450 -- --test --shots=/папка`
  (идёт медленно — программный рендер, 2–3 кадра в секунду; запускать в фоне)
- быстрый просмотр рук (1–2 мин): `xvfb-run ... $GD --path . --rendering-method gl_compatibility --resolution 800x450 res://tests/arms_preview.tscn -- --out=/папка`
- быстрая проверка картинки ключевых сцен: автотест с `--quick`
- сборка для Windows: `$GD --headless --path . --export-release "Windows" build/STENA.exe`
